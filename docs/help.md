# 使用与排查

## 打字时猫咪没有反应

1. 右键猫咪、Windows 托盘图标或 Mac 菜单栏图标，打开「帮助与反馈 → 使用说明」，看「键鼠互动」的状态。如果显示已暂停，从菜单选「恢复键鼠互动」。
2. 在普通输入框连续敲 `xiaoyu` 或 `fish`，猫咪会抱鱼。点「单词彩蛋 → 打字触发彩蛋」控制动作，点「显示按键气泡」控制字母和整词。也可以用双拼、五笔或粘贴输入完整的中文口令。
3. Mac 需要「输入监控」。从桌宠菜单选「启用跨应用键盘互动…」，也可在「系统设置 → 隐私与安全性 → 输入监控」中开启爪爪。macOS 11、12 的入口是「系统偏好设置 → 安全性与隐私 → 隐私」。系统要求重新启动时，请退出并重新打开爪爪。
4. 若只有一个应用表现不同，请用同一个示例词在另一款文本编辑器中比较。Windows 在无法识别的自绘窗口里可能只显示交替敲爪。微信主聊天窗口支持键帽和整词气泡；独立弹窗按实际控件识别。

## 中文彩蛋

连续敲出下面的拼音，最后一个字母按下时，猫咪就开始表演。中文和英文输入模式都可以。比如敲完 `xiaoyu`，之后选「小雨」「小鱼」或直接取消候选，都只播放这一次抱鱼动作。

| 气泡 | 拼音 | 动作 |
| --- | --- | --- |
| 你好 | `nihao` | 看向你，挥两下爪再点头 |
| 爱心 | `aixin` | 双爪把心捧到胸口，跟着心跳轻轻起伏 |
| 小鱼 | `xiaoyu` | 凑近小鱼，啃两口 |
| 晚安 | `wanan` | 点两次头，歪头打盹 |
| 跳舞 | `tiaowu` | 左右踏步并脚，交叉摆爪，收拍小跳 |
| 来财 | `laicai` | 招两下爪，目光跟着金币 |
| 敬自己一杯 | `jingzijiyibei` | 向前碰杯，再收回来喝一口 |
| 硬控 | `yingkong` | 突然定住，停一会儿再抖开 |
| 鸡你太美 | `jinitaimei` 或 `jntm` | 两次运球、换手、转肩踩步、收球 |
| 蜜雪冰城甜蜜蜜 | `mixuebingchengtianmimi` 或 `mxbctmm` | 侧步举甜筒，用另一只爪画心，再谢幕 |
| 干饭时间 | `ganfanshijian` | 一爪扶碗，另一爪舀饭送到嘴边，分两口吃 |
| 一键三连 | `yijiansanlian` | 蹲伏起跳，肉垫依次按向屏幕上的赞、币、星，再落地 |

中文输入模式下，用空格或数字分段选词也能接着拼。例如，敲 `jing` 选词后接着敲 `zijiyibei`，最后一个 `i` 会触发举杯。换窗口、退格或按快捷键会清除尚未拼完的口令。Mac 的跨应用键鼠互动使用系统的「输入监控」权限。

同一次输入的拼音和上屏汉字命中同一彩蛋时，只表演一次。立刻再输一遍也能再演。表演中再触发会排在当前动作之后。简体、繁体均可。Mac 可从「单词彩蛋 → 启用汉字词匹配」授予辅助功能权限。Windows 和 Mac 在提供文字接口的普通编辑框里核对汉字，只提供主窗口的微信等自绘界面可以用拼音或简拼。

可以在[动作预览](preview.gif)中看三连、换步舞和甜筒舞。程序和画稿体积见[彩蛋资源实测](word-trick-costs.md)。

## 锁定和解锁

右键猫咪或从托盘、菜单栏选择「锁定桌宠（点击穿透）」。锁定只影响直接操控，打字动画和彩蛋会继续。点猫咪右上角的小锁即可解锁。透明度设置只作用于猫咪，小锁始终清晰可见。

在普通输入框连续敲 `jinitaimei` 或简拼 `jntm` 可以触发「鸡你太美」运球舞，也可以从「单词彩蛋」点播。

## 安装和升级

Windows 版可以直接运行。从旧版升级时，先在托盘退出旧桌宠，再打开新版。Mac 请退出旧版，将新的 `PawPaw.app` 放入「应用程序」，再从新图标启动。此前的角色、穿搭、透明度和位置沿用。Mac 可能会要求重新确认输入监控权限。

从「回到屏幕右下角」可以找回移出视野的猫。双击猫咪会捧心，右键「单词彩蛋」可试演动作。

## 核对下载文件

从同一版的发布页下载 `SHA256SUMS.txt`，对照对应文件名的 SHA-256 值。

Windows PowerShell：

```powershell
Get-FileHash .\PawPaw-Windows.exe -Algorithm SHA256
```

Mac 终端：

```sh
shasum -a 256 PawPaw-macOS-universal.zip
```
